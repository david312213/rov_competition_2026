# 群体盲抓与跳跃式离底搜索

## 这是什么

这是与原有单目标测试并存的独立实验流程：

```text
重新触底标定 → 上浮 0.15m 并定深 → 360° 扫描
  ├─ 无 6 个扇贝群：前进 0.40 × 2s → 重新触底
  └─ 确认群体：对准 → 靠近 → 触底盲抓 3 次
       → 离开当前群 → 重新触底搜索
```

压力深度不是离底测距。没有下视声呐时，程序只能在每次换位后
重新触底，再用压力深度上浮 `0.15m`。短距离前进期间无法发现
突然隆起的地形，所以必须分阶段实艇验收，不能把它宣传成地形跟随。

## 解锁前条件

- ROV 完全浸没，危险区无人，安全员可物理断电；
- QGC 已有实时遥测、`5600` 画面和人工上锁能力；
- 操作员已把飞行模式切为 `ALT_HOLD`；
- `robot.yaml` 为 `commissioning`，允许真实输出和 ROS 解锁；
- `rst` 机械爪已在断开推进器的台架测试中真实完成开、闭，
  已被激活且允许机械爪输出；
- `command_limit` 不小于现场使用的最大 power；
- 其他 WASD、手柄、自主和测试控制节点已停止。

程序要求输入固定下潜 power（默认 `0.60`，范围 `0.10～0.80`），
然后完整输入：

```text
START CLUSTER COLLECTION
```

确认词正确后才会开运行许可和解锁。

## 识别、对准和靠近

- 只统计模型类别 `scallop`；
- 框中心归一化距离不超过 `0.18` 的检测框归入同一连通群；
- 同一候选群最近 5 个新帧中至少 3 帧达到 6 个扇贝才锁定；
- 群中心是各框中心中位数，锁定后做轻度平滑；
- 水平误差超过 `0.12` 只转向，绝不前进；
- 误差进入 `0.08` 且稳定 3 个新帧后才靠近；
- 群中心 `y < 0.55` 时前进 `0.20`，`0.55～0.70` 时前进 `0.10`；
- 默认在居中且群中心达到 `y=0.70`，最近 5 帧至少 4 帧满足时下降。

第一张完全漏检帧立即停止前进；连续 5 个新帧且距最后一次
匹配至少 `0.80s` 才确认丢失。重复帧不增加任何计数。

`cluster_collection.yaml` 中有 `image_line / union_area / both` 三种下降
判据。初次实艇只使用 `image_line`；面积模式没有填实测阈值时
配置校验会拒绝启动。

## 三次盲抓不等于三次成功

每一次流程是：开爪 ACK → 下降疑似触底 → 回中 → 闭爪 ACK
→ 等机械动作 → 闭爪上浮 0.15m → `TRANSFER_TO_NET` 等待记录
→ 重新开爪。前两次之间前进 `0.20 × 0.5s`，第三次后离开
当前群 `0.40 × 2s`。

记录中的“抓取尝试”只代表飞控接受了爪子指令，不能证明实物
已被抓到。`TRANSFER_TO_NET` 目前是定时回中等待，没有网兜机械动作。
若开、闭爪服务拒绝或超时，程序不会增加抓取次数；深度反馈仍健康时
先回到启动深度再上锁，深度失效时则立即升级为急停，禁止盲目上浮。

## 操作和验收顺序

| 操作 | 效果 |
|---|---|
| `Space` | 立即回中并暂停 |
| `Enter` | 画面与遥测新鲜时恢复 |
| `0` | 正常回到启动深度、上锁并结束 |
| `Esc` / 关闭控制窗口 / `Ctrl+C` | 回中、请求急停与上锁 |

必须按以下阶段逐项验收，不能第一次就跑三次自动盲抓：

1. 真实输出关闭，只看群体框、中心、`y=0.70` 线和数量。
2. 水中只执行群体偏航对准，不前进。
3. 靠近到线后停车，不下降。
4. 只下降一次，机械爪保持断开。
5. 单次盲抓。
6. 确认每个中止、丢帧、爪子 ACK 失败和人工上锁路径后，才进行一群三抓。
7. 最后才连续寻找下一群。

单次任务最长 15 分钟，到时后自动走正常回收。结果在：

```text
output/cluster_collection_tests/YYYYMMDD_HHMMSS/
├── video_raw.mkv
├── events.csv
├── detections.csv
├── clusters.csv
├── grasp_attempts.csv
├── session.json
└── logs/
```

`clusters.csv` 会逐帧保存所有候选群，并用 `locked` 标记当前锁定群，
方便赛后复查“为什么选了这一群”。
