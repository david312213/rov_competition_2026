# 搜索、接近与抓取位置标定：一键使用说明

## 两个入口有什么区别

两个入口共用同一套 `0.2.0rc2` 状态机，都会先执行：

```text
输入相对下潜距离
→ 下潜到“启动深度 + 输入距离”
→ 向右按真实航向扫描 360°
→ 没找到时前进 2 秒，再扫描，最多三轮
→ 最近 5 个新帧中至少 3 帧命中后锁定目标
→ 只用偏航把目标稳定对准
```

稳定对准后，两种流程才分开：

```bash
# A：继续自动接近；框面积稳定达到 0.10 后回收，不闭爪
./scripts/start_search_approach_test.sh

# B：立即停止自动运动，进入 WASD 人工精调和实抓记录
./scripts/start_grasp_position_test.sh
```

这两个入口都是水池测试，不会改写正式自主任务参数。人工标定生成的建议也
只供人审核，不会自动复制到 `autonomy.yaml`。

## 一次性配置 BlueOS 与 QGC

岸上有线网卡保持 `192.168.2.1/24`。在 BlueOS 中保存四个输出：

```text
MAVLink UDP Client：192.168.2.1:14550（QGC）
MAVLink UDP Client：192.168.2.1:14551（ROS）
摄像头 UDP：udp://192.168.2.1:5600（QGC 默认视频）
摄像头 UDP：udp://192.168.2.1:5700（软件副流）
```

QGC 开启 UDP 自动连接，视频恢复默认 `5600`，并开启 Low Latency。删除过去
手工创建的通信和视频链路。设置保存后，以后开机不再改 QGC 端口。

岸上软件只处理副流：

```text
5700 → 5702 YOLO
     └→ 5704 原始 MKV 录像
```

## 运行前必须满足

- ROV 已完全浸没，推进器危险区无人；
- 一名操作员，一名只负责 QGC 上锁和物理断电的安全员；
- QGC 已连接、视频正常，并由操作员手动切到 `ALT_HOLD`；
- `config/robot.yaml` 使用 `commissioning`，允许 `ALT_HOLD`；
- `command_limit` 建议为 `0.80`，且真实输出和 ROS 解锁已经通过单轴验收；
- 键盘采集、手柄控制发布器、正式自主节点和其他测试工具全部停止；
- 自动接近模式必须保持机械爪权限关闭；
- 人工标定中的 `C/O` 只有在机械爪候选档案已实物通过并人工启用后才可用。

脚本会检查 `192.168.2.2`、默认 QGC 端口、ROS 网关、GPU、权重、软件
视频、录像和感知话题。任何一项不符合都会在解锁前停止。

## 启动与下潜参数

```bash
cd /home/persica/rov_competition_2026
./scripts/start_search_approach_test.sh       # 自动接近
# 或
./scripts/start_grasp_position_test.sh        # 人工抓取标定
```

程序会询问：

```text
相对下潜距离（米）[默认0.30]：
下潜最大power [默认0.60，范围0.10～0.80]：
```

确认屏幕显示的启动深度、相对下潜和目标深度正确后，完整输入：

```text
START SEARCH TEST
```

确认词正确后才会申请运行许可并解锁。它不会自动切换飞行模式。
距目标深度还有 `0.20 m` 以上时，使用本次输入的最大 power；
进入最后 `0.20 m` 后自动线性减速。网关总限幅仍以
`robot.yaml` 的 `command_limit` 为准。

## 自动接近模式

- 扫描：键 `2` 对应方向，偏航 power `0.20`，航向闭环一整圈；
- 无目标：键 `W` 对应方向，power `0.40` 前进 `2.0 s`；
- 对准：左侧框向右转，右侧框向左转，不自动横移或升沉；
- 接近：框较小时前进 `0.20`，接近阈值时降为 `0.10`；
- 偏差超过 `0.12` 时立即停车并重新对准；
- 最近 5 个新帧至少 4 帧同时满足居中和面积 `0.10` 后才回收；
- 本模式不会发开爪或闭爪命令。

第一帧漏检会立即停止前进，但仍保留目标锁；连续 3 个新帧没有匹配框，
并且距最后命中至少 `0.30 s`，才确认目标丢失。超过 `1.0 s` 没有新鲜
图像会急停中止，不会使用积压画面继续运动。

## 人工抓取位置标定模式

稳定对准后，窗口显示 `MANUAL_CALIBRATION`，自动运动停止。此后由同一个
ROS `commissioning` 来源控制，不能同时用 QGC 手柄发送运动命令。

| 按键 | 功能 |
|---|---|
| `W / S` | 前进 / 后退 |
| `A / D` | 左移 / 右移 |
| `1 / 2` | 左转 / 右转 |
| `↑ / ↓` | 上升 / 下潜 |
| `+ / -` | 人工 power 每次增减 `0.01`，范围 `0.05～0.40` |
| `Space` | 立即四轴回中，保持当前深度 |
| `Enter / G` | 保存闭爪前的框、遥测和截图 |
| `C` | 对已保存样本发送一次闭爪命令 |
| `O` | 单独发送一次开爪命令 |
| `Y / N` | 观察实物后，标记本次抓取成功 / 失败 |
| `B` | 保存为明显不合格位置，不闭爪 |
| `R` | 回到本轮搜索深度，再完整扫描 360° |
| `0` | 正常回到启动深度、上锁并结束 |
| `Esc` / 关闭窗口 / `Ctrl+C` | 回中、急停、尝试上锁 |

移动键必须按住才运动，松开立即回中；窗口失去焦点也会回中并暂停。回到
窗口后按 `Enter` 恢复。人工 power 默认 `0.10`。

一次有效实抓必须严格按顺序：

1. 用 WASD、方向键和 `1/2` 调到认为能抓住的位置；
2. 松开按键，按 `Enter/G` 保存闭爪前证据；
3. 按 `C`，服务接受后观察真实机械爪；
4. 确实抓住按 `Y`，未抓住按 `N`；
5. 按 `O` 开爪，调整位置后继续记录，或按 `R` 重新搜索。

没有先保存时 `C` 会被拒绝；闭爪服务没有返回“已接受”时，`Y/N` 也会被
拒绝。这里记录的是 ROS 网关的服务响应，不是执行器位置反馈；服务返回成功
只代表命令被接受，不能替代人对实物的判断。

## 正常结束与急停的区别

- `Space`：只回中。自动阶段还会暂停，按 `Enter` 才恢复；它不是结束键。
- `0`：正常结束，使用有效深度反馈回到启动深度，随后正常上锁。
- `Esc`、关闭窗口或 `Ctrl+C`：异常中止，立即回中并请求急停上锁；不会
  在关键数据失效时盲目上升。

QGC 始终保留人工上锁能力。如果软件无法确认急停，安全员必须立即用 QGC
上锁或物理断电。

## 记录文件

自动接近模式保存：

```text
output/search_tests/YYYYMMDD_HHMMSS/
├── video_raw.mkv
├── events.csv
├── detections.csv
├── session.json
└── logs/
```

人工标定模式保存：

```text
output/grasp_tests/YYYYMMDD_HHMMSS/
├── video_raw.mkv
├── events.csv
├── detections.csv
├── grasp_samples.csv
├── screenshots/
├── recommended_grasp.yaml
├── session.json
└── logs/
```

每类少于 5 个成功样本时，建议文件只写“数据不足”。样本足够后，瞄准点
使用成功样本中心的中位数，面积阈值使用成功面积的保守分位数；仍须结合
失败截图人工审核。单目框面积不是实际距离。

## 明日固定顺序

1. 配好 BlueOS 四个默认输出，确认 QGC 不用自定义链路也有遥测和画面。
2. 物理断开推进器，先运行 `./scripts/start_gripper_test.sh dalian`。
3. 上锁、断电、重新查线；只有满足 RST 条件时再运行
   `./scripts/start_gripper_test.sh rst`。
4. 保持机械爪权限关闭，运行自动接近模式，验收转圈、目标确认、对准、
   漏检停车和自动接近。
5. 启用已经实物通过的机械爪档案，运行人工标定模式。
6. 多次执行“精调 → 保存 → 闭爪 → Y/N”，同时保留成功、失败和不合格样本。
7. 按 `0` 正常回收，检查录像、CSV、截图、日志和建议文件。

若 BlueOS 双视频输出使全长水密缆花屏或丢包明显增加，停止实艇测试，改回
单路视频到岸上后再复制；不要通过放宽感知超时继续盲走。
