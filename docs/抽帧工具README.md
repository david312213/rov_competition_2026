# ROV 视频抽帧软件

这个工具用于把采集录像转换成待筛选、待标注的图片。它是独立桌面软件，
不会启动 ROS、YOLO、MAVProxy，不连接飞控，也不会修改原视频。

## 一键打开

安装环境后，在一个终端运行：

```bash
cd /home/persica/rov_competition_2026
./scripts/start_frame_extractor.sh
```

也可以把某个视频路径直接交给它：

```bash
./scripts/start_frame_extractor.sh /完整路径/video_raw.mkv
```

## 安装成 Ubuntu 应用

只需安装一次快捷方式：

```bash
cd /home/persica/rov_competition_2026
./scripts/install_frame_extractor_shortcut.sh
```

之后在 Ubuntu 应用列表搜索“ROV 视频抽帧”，点击图标即可打开，不用再
输入终端命令。若更新了工程位置，需要重新运行一次快捷方式安装脚本。

## 怎么使用

1. 把一个视频拖进蓝色区域；也可以点击该区域选择文件。
2. 软件显示分辨率、帧率、总帧数、时长和预计图片占用空间。
3. 在“输出帧数”填 `0` 导出全部，或填 `1` 到视频总帧数之间的数字。
4. 默认使用 JPG 质量 95；需要无损图片时可以选择 PNG，但占用会很大。
5. 默认输出目录已经自动填写，也可以点击“选择位置”更换磁盘。
6. 点击“开始导出”，完成后点击“打开输出目录”。

## 输出帧数怎么分

- `0`：导出全部可解码帧。
- `1`：取视频正中间的一帧。
- `2`：取第一帧和最后一帧。
- `3` 及以上：从视频开头到结尾均匀分布，并包含首尾。

例如原视频有 1000 帧，输入 `5`，将取源帧序号
`0、250、500、749、999`。界面会在开始前显示分配方式，便于核对。

软件仍然会按顺序扫描完整视频，只保存选中的帧。这样对 MP4、MKV 等
压缩视频更可靠；选得少会明显节省图片数量和硬盘空间，但处理时间不会按比例
缩短。

## 输出结构

默认位置：

```text
output/extracted_frames/视频名_YYYYMMDD_HHMMSS/
├── images/
│   ├── frame_00000001.jpg
│   ├── frame_00000002.jpg
│   └── ...
├── frames.csv
└── extraction.json
```

- `images/`：所有成功解码的帧图片；
- `frames.csv`：图片名、原视频帧序号和对应时间；
- `extraction.json`：原视频信息、导出数量和完成状态。

每次都会生成带时间的新目录，不会覆盖以前的数据。

## 取消和异常

点击“取消”或在导出时关闭窗口，软件会等待当前图片写完，再安全停止。
已完成的图片不会被删除，`extraction.json` 会标记 `cancelled`。

发生磁盘不足、视频损坏或编码不支持时，软件保留已完成图片并标记
`failed`，不会把半份结果写成“完成”。图片写入采用临时文件再改名，
尽量避免突然中止留下半张正式图片。

## 硬盘容量提醒

“视频只有几百 MB”不代表所有帧图片也只有几百 MB。视频利用了帧间
压缩，而导出的 JPG/PNG 每一张都是独立图片。1080p 长录像可能产生
几万张图片和数 GB 到数十 GB 数据。

软件会抽取代表帧估算容量，并保留至少 512 MiB 磁盘安全余量。预计空间
不足时会拒绝开始；导出期间可用空间低于余量也会安全停止。

## 后续做数据集时

不要把 `images/` 中每一张图片直接全部标注。相邻帧往往几乎相同，建议：

1. 先删除模糊、严重花屏和完全重复的帧；
2. 保留不同距离、角度、光照、遮挡和背景；
3. 保留一定数量的无目标负样本；
4. 按不同录像片段划分训练集和验证集，避免相邻帧泄漏。
