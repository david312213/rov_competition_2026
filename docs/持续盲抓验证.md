## 2026年9月17日完成内容

- 主状态机改为启动即下潜，首次压力深度稳定3秒或10秒定时兜底后开始抓取。
- 每次完整执行张爪、抓取前进、闭爪、转筐、投放和回位。
- 每次投放后以 `+0.415` 上潜2秒，蛇形移动后以 `-0.415` 下潜5秒。
- 每条带由四个5秒前进段组成；到带尾横移4.5秒并转艇11.5秒，左右逐带交替。
- 删除10次批次上限、4框确认、30秒视觉降级和视觉断流状态转换，动作永久循环。
- `/rov/detections` 仅用于框数日志和带框查看器；0框、100框、重复帧、断流和解析异常均不改变指令时间线。
- 模型、视频分发、查看器和录像失败后独立重试。MAVLink、官方ROS和官方TCP异常不会暂停状态机。
- 保留S11夹爪730张开/575闭合，以及S10机械臂1810筐位/710抓取位。
- 旧本机配置缺少 `vertical` 和 `route` 时自动采用当前默认值；旧视觉触发字段被忽略。
- 人工关闭仍发送运动归中并释放控制。
- 一队官方端口40198、二队 `ddhyzx2` 官方端口40197，并提供不会混用端口的队伍启动脚本。
- 原始H.264视频随盲抓辅助链路推送到所选队伍的官方RTMP地址；失败后重试且不停止动作。

## 自动测试

本次在macOS、Python 3.13.12上运行完整回归；此前同一盲抓基线已在Python 3.10.20上通过：

```bash
python -m pytest -q
```

结果：

```text
402 passed in 5.19s
```

覆盖内容包括：

- 首次下潜方向、最小下降量、3秒稳定深度平台和10秒无深度兜底。
- 六个机械动作阶段的PWM组合、持续时间和闭爪指令计数。
- 上潜2秒、前进5秒、下潜5秒的循环顺序。
- 四段20秒前进带、横移、转艇以及正负方向交替。
- 视觉有框、无框和异常时完全一致的运动输出。
- 深度在首次抓取以后不再影响状态转换。
- 连续1000次完整抓取后仍进入下一次循环，不存在结束状态。
- 视频、模型、录像、查看器、深度读取和通信输出异常下的持续运行。
- MAVLink连接、收发异常后的重连与当前姿态重发。
- MAVLink 1和2真实本机UDP回环中的下潜、前进、舵机、归中和通道释放报文。
- SIGINT、SIGTERM和SIGHUP三种人工关闭流程。
- 官方消息字段、话题、遥测换算、TCP节点退出重启和运动方向同步。
- 两队端口选择、旧本机配置保留，以及官方RTMP参数进入视频分流。
- 旧配置兼容、配置解析、Bash/Python语法及其余工程回归测试。
