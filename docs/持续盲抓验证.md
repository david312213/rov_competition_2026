# 持续盲抓实现与验证记录

## 已完成

- 独立 `rov_blind_grab` 入口、配置模板和启动脚本。
- 复用原定时蛇形动作值和左右交替顺序，搜索进度可冻结/恢复。
- 停车后5张新图并覆盖至少1秒的4框确认。
- 每批3次开爪、行进、闭爪、转筐、投放、回位；批内不因视觉变化中止。
- 只累计找框时间的30秒降级，4直接变0，永久盲抓状态不会被视觉恢复清除。
- 独立MAVLink输出、ROS检测接收和视频/感知辅助进程；没有原网关的任务门控。
- 手动关闭后运动归中、释放控制、清理本入口拥有的辅助进程。

## 测试结果

在 macOS、Python 3.12.14 上运行：

```text
python -m pytest -q
384 passed in 4.47s
```

新增48项测试。关键覆盖：

- 同一帧重复读取、短时间大量帧、检测中断、瞬时误检、截止时刻同时收到框。
- 搜索各阶段的立即停车、3次抓取后的剩余搜索时间恢复。
- 单批动作超过30秒不触发降级；永久模式连续1000次动作循环。
- 模型/相机数据源异常、视频/感知/录像/查看器启动失败或退出。
- MAVLink连接、接收、发送失败后重试；不等待遥测、心跳或舵机ACK。
- 使用真实pymavlink，仅向测试自身的 `127.0.0.1` 临时UDP端口发送和解析报文。
- MAVLink 1和2的归中/释放格式；SIGINT、SIGTERM、SIGHUP关闭流程。
- Python 3.10语法兼容检查、启动脚本Bash语法检查。
