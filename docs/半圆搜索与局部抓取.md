# 半圆搜索与局部抓取

这是在 e371b48 基础上增加的独立策略。原群体收集入口仍保留；新入口为
`scripts/start_semicircle_collection_test.sh`。本版本通过纯软件测试不等于完成实艇验收。

## 场地与坐标

右侧墙壁为半圆直径，生物集中区向左展开，从直径下端附近出发，初始机头平行墙壁朝向直径另一端。
内部坐标 x 正方向远离墙，y 正方向沿初始机头；圆心为 (0, D/2)。
采用避墙、避弧边后的平行弦蛇形路线，向外逐行缩短。
有效圆半径 r=D/2-edge_margin_m，弦端点为 y=D/2 ± sqrt(r²-x²)。
相邻弦端点的 x、y 都不同：连接段同时改变两个坐标，不能仅横移后反向。

实际投放后需人工把机器人放在第一条内缩弦的下端附近并摆正航向；程序把这作为初始推算位置。
原始直径端点与第一条搜索带之间的移动目前由操作员完成，不能把未知投放偏差当作已测量的位置。
行距需小于经实测确定的可靠识别带宽，并预留重叠。代码无法自行验证视野覆盖宽度。

## 流程

1. 下降到人工检查地形后确认的观察压力深度，稳定后开始搜索。不再利用“深度不变”自动判定触底。
2. 沿当前搜索带低速前进，罗盘航向误差过大时先停车转向。
3. 发现单个 scallop 后停车，以多个新帧确认。选择实际检测框，不对准多个目标之间的空地。
4. 复用原图像偏航对准/远近接近控制。达到标定图像线后请求开爪，执行有限下降、闭爪、抬升。
5. 保持闭爪等待人工转运；操作员确认已完成转运且允许重新开爪时按 T。程序没有网兜执行机构，不自动假定已入网。
6. 开爪反馈后重新观察、重新确认和对准；局部尝试次数、停留时间或推算位移达到上限则结束该观察点。
7. 恢复观察深度并重新指向尚未完成的计划航点。移动一定推算距离前抑制再次锁定，减少立即回到同一目标。
8. 全部计划航点完成、任务时间/推算里程到限，进入回到启动深度流程。没有自动返回投放点功能。

局部次数在发出一次新的抓取开爪请求时增加；机械爪命令失败进入故障回收，不无限重试。
`total_grasp_attempt_count` 仍按原接口记录闭爪 ACK 次数，二者均不表示成功收获数量。
局部上限在对准、接近、重新观察阶段检查；已开始的有限抓取/抬升先结束，避免在动作中间强制水平离开。
转运有单独超时，到时保持闭爪请求正常回收。总任务时限始终有效。

## 推算的边界

无DVL/水平定位，x、y来自各阶段实测速度×有效运动时间及航向投影。
搜索、接近产生的位移都更新推算位置；抓取不直接推进航点编号。
暂停与机械爪服务等待期间不累计指令里程；水流、线缆拖曳、制动惯性、原地漂移不在估计内。
转向闭环只维持机头方向，不保证真实航迹平行，也不能保证实际不越界。
局部离开抑制采用推算距离，不是永久目标ID或区域地图，仍可能重复抓取。
完成标记只说明推算航点完成，不说明实际全覆盖。

观察深度是压力深度，不是离底距离。地形变化时没有自动地形跟随；需操作员暂停调整或结束。
有限抓取下降量按现场标定填写，不能保证在所有地形抓取成功或避免接触海底。

## 配置与入口

复制 `ros2_ws/src/rov_competition/config/coverage.example.yaml` 为
`config/coverage.local.yaml`，根据实际测量填写全部 null。该本地文件被 Git 忽略。
模板故意没有填写“约10m”或任意速度、重试次数；它们不是现场测量值。

- 场地：直径、墙/弧边余量、行距、航点容差。
- 运动：搜索控制量及实测速度，原 cluster 配置中远/近前进控制量所对应的实测速度；转向增益与超时。
- 局部：最大尝试数、停留时间、最大估算移动量、离开后抑制距离、重新观察时限。
- 垂直：观察压力深度、最后下降量、上下控制量、稳定时间、深度容差与超时。
- 视觉：实际机体的图像方向、水平对准点、接近减速位置、下降线。
- 整体：任务/路段时限、最大估算路程、循环间隔与航向跳变容差。
- `field_calibrated` 仅在上述参数与实艇条件确认后设 true，不会自动放开 robot.yaml 权限。

新入口复用原群体运行时和通信链路，仍需 Ubuntu/ROS、现有QGC与RST机械爪条件。
脚本使用已有录像链路作为测试记录；未重新开发视频工具。

```bash
bash scripts/start_semicircle_collection_test.sh
```

或在原运行时传入 `--coverage-config /实际路径/coverage.local.yaml`。
解锁前要求输入 `START SEMICIRCLE COLLECTION`。
Space暂停、Enter恢复、0正常结束、Esc/关闭控制窗口/Ctrl+C急停。
T仅在转运等待状态且未暂停、感知健康时有效，含义是“转运已完成，允许开爪”。

原会话目录额外保存 `resolved_coverage.json` 和 `coverage_estimates.jsonl`。
每行明确标注 `command_time_dead_reckoning`；记录航点、搜索带、局部尝试数和单目标中心。

## 已实现与现场待办

已实现：半圆几何、航向控制、指令里程推算、单目标确认/跟踪、有限抓取、局部上限、重新观察、抑制立即重抓、人工转运确认、运行入口、日志与离线测试。
待实测：全部现场参数、初始位置/朝向、底部起伏下的深度选择、抓取对准关系、真实行驶漂移、机械爪及入网兜流程。
未实现：水平定位、真实离底测距、成功抓取检测、自动网兜转运、目标永久去重、精确回到起点。
