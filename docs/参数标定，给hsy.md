# 参数标定

## 1. 只从 `field_tuning` 开始改

文件：`ros2_ws/src/rov_competition/config/autonomy.yaml`。

每次改动必须记录：日期、艇体负载、电池电压、水池、水况、改前值、改后值、测试录像和结论。不要一次改多个互相影响的量，否则无法判断是哪项改变产生了结果。

## 2. 相对下潜

默认：

```yaml
descent_delta_m: 0.30
descent_tolerance_m: 0.05
```

先验证深度正方向：ROV 实际下沉时 `/rov/telemetry.depth_m` 必须增加。用已知水深检查零点和单位；若数据反向或比例不对，先修 `robot.yaml` 的深度换算，不要用状态机增益“抵消”传感器错误。

在完全浸没、固定安全区内记录启动深度和最终深度。先看是否稳定进入容差，再调 `descent_gain`；不要一开始提高 `descent_max_command`。

## 3. 无 DVL 的 0.40 m 前进估算

必须在与比赛相近的电池、浮力、负载和水况下做：

1. 固定使用 `advance_forward_command: 0.05`。
2. 在池边布置可量取的起点和终点，摄像记录。
3. 每次只运行短时间，至少重复 5 次。
4. 分别记录实际时间与人工测得距离。
5. 计算每次 `速度 = 距离 / 时间`，剔除有碰撞、缆绳拉扯或明显流场干扰的失败样例。
6. 用保守的代表速度填写 `advance_estimated_speed_mps`。

例如实测同工况平均约 `0.20 m/s`，只改：

```yaml
advance_estimated_speed_mps: 0.20
```

状态机自动得到 `0.40 / 0.20 = 2.00 s`，不存在另一个需要同步维护的持续时间参数。

这仍是估算。电量、挂载、缆绳和水流变化后必须重测。

## 4. 图像控制方向

状态机定义：

- `horizontal_error > 0`：框中心在瞄准点右侧；
- `vertical_error > 0`：框中心在瞄准点下侧；
- `yaw > 0`、`vertical > 0` 的真实艇体方向还要经过 `robot.yaml` 的逐轴方向配置。

标定顺序：

1. 先用 `rov_axis_test` 确认艇体正方向，没有这一步不能标图像方向。
2. 放置一个稳定目标，让它明显位于瞄准点右侧。
3. 人工只给极短、极小的正偏航点动，观察目标是否朝瞄准点移动。
4. 若正偏航能减小误差，`image_yaw_sign: 1`；若负偏航才能减小误差，填 `-1`。
5. 用目标在左侧复验，必须同样收敛而不是发散。
6. 按相同步骤标定 `image_vertical_sign`，并同时在目标位于瞄准点上方、下方时复验。

摄像头安装方向一旦改变，就重新标定。完成录像复核后才把：

```yaml
image_control_confirmed: true
```

## 5. 抓取瞄准点

默认 `(0.50, 0.70)` 不是画面几何中心，而是根据前置机械爪预留的偏下位置。把目标放在机械爪真正可以进入的轨迹上，观察框中心落在画面哪里，再填写比例。

不要为了让数值“好看”固定为 `(0.50, 0.50)`；瞄准点由摄像头和机械爪的相对安装决定。

## 6. 每类框面积阈值 `k`

框面积比：

```text
k_observed = 框宽 × 框高 / (画面宽 × 画面高)
```

标定时每个类别分开做：

1. 机械爪打开，ROV 固定或极低速接近。
2. 在“可以安全闭爪但尚未碰撞”的距离停止。
3. 记录至少 20 张不同角度、光照和姿态的有效框。
4. 同时保存漏检、遮挡、贴屏、框跳变等失败样例。
5. 选择一个保守阈值，保证正常接近能达到，又不会在距离过远时提前闭爪。
6. 分别填写 `echinus`、`holothurian`、`scallop`、`starfish`。
7. 回放所有失败样例，确认异常大框和单帧检测不会闭爪。

默认 `0.18` 只是起点。四类都完成水池录像和人工复核后，才设置：

```yaml
grasp_thresholds_confirmed: true
```

## 7. 水平运动确认

只有前后、横移、升沉、偏航方向，松杆/中位，`Ctrl+C`，发布者崩溃和 MAVLink 断链都通过后，才设置：

```yaml
horizontal_motion_confirmed: true
```

这个布尔值是验收记录，不是“让代码先跑起来”的开关。

## 8. 最后开启真实自主

完成全部标定后，仍需人工把两道授权从 `false` 改为 `true`：

```yaml
mission:
  allow_autonomous_mission: true
  allow_open_loop_horizontal_motion: true
```

若启动被拒绝，完整阅读服务返回的缺项列表，不要删除检查逻辑。
